# Boîte à outils de gestion commerciale

## Description
Ce projet est une application Python qui facilite les calculs de gestion commerciale.

## Fonctionnalités
- Calcul de la marge commerciale.
- Calcul de la TVA.
- Calcul des intérêts.
- Calcul du total des ventes.

## Technologies utilisées
- Python
- Git
- GitHub

## Exécution
Pour lancer le programme, exécuter :

    python main.py

## Objectif
Mettre en pratique les outils collaboratifs Git et GitHub dans le cadre de la Licence Business Data Analysis.
